# Security Policy

## Supported versions

The latest commit on `main` is the supported development version. This extension is an early pilot and has not undergone an independent security audit.

Never include a real candidate profile, resume, application screenshot, authentication token, or employer response in a public issue or commit.

The extension is intended for a dedicated browser profile. Keep it disabled outside application sessions. Review host permissions and source changes before loading an updated version.

## Reporting a vulnerability

Use the repository's **Security > Report a vulnerability** flow. Do not include private application data in a public issue.
